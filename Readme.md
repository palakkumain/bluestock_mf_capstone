# BlueStock Fintech – Mutual Fund Analytics (Day 2)

## Project Overview
This project focuses on cleaning mutual fund datasets, designing a SQLite star schema database, and performing SQL-based analysis.

## Objectives
- Clean and validate mutual fund datasets.
- Standardize date and transaction formats.
- Remove duplicates and handle missing values.
- Create a SQLite database with a star schema.
- Write analytical SQL queries.

## Tools Used
- Python
- Pandas
- NumPy
- SQLite
- SQLAlchemy
